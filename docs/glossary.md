# Glossary

Short definitions of the lifecycle terms used across this repository. Each
entry points at the document that defines the term in full.

- **Stage**: one of the nine lifecycle stages a work item moves through,
  recorded on the issue as a `stage:*` label; see `docs/lifecycle.md`.
- **Risk tier**: the assessed risk of a change, one of low, medium, high, or
  critical, recorded on the issue as a `risk:*` label; see
  `docs/risk-assessment.md`.
- **Work item**: a GitHub issue created from the work item template, which
  starts the lifecycle; see `.github/ISSUE_TEMPLATE/work-item.yml` and
  `docs/lifecycle.md`.
